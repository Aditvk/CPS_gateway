\begin{abstract}
Multimodal Large Language Models (MLLMs/VLMs) that accept visual tokens alongside textual prompts are increasingly vulnerable to indirect prompt injection attacks, wherein adversaries conceal adversarial commands within image pixels to hijack model behavior, exfiltrate private contexts, or bypass safety guardrails. Current defenses are overwhelmingly single-layered: either relying on textual input filtering (which fails when instructions are encoded in visual steganographic channels) or inspecting representation activations (which incurs severe latency and lacks model-agnostic deployability). In this paper, we propose a cloud-deployable, model-agnostic middleware gateway anchored on a novel \textit{Dual-Gate} security architecture. \textbf{Gate 1} enforces cryptographic provenance via asymmetric Elliptic Curve Digital Signatures (ECDSA P-256), establishing non-repudiation and providing a sub-millisecond fast-path for verified sources. \textbf{Gate 2} acts as a zero-trust fallback for unsigned or unverified assets, deploying a deep convolutional steganalysis network (\textit{Xu-Net}) equipped with a fixed high-pass residue filter to detect subtle perturbation signatures across spatial and frequency domains. Unverified images flagged by Gate 2 are dynamically diverted to a multi-stage perceptual sanitization pipeline that neutralizes steganographic payloads while preserving visual semantic utility. We evaluate the gateway against real-world multimodal prompt injection payloads synthesized over the BOSSbase benchmark and custom visual prompt corpora. Our empirical findings demonstrate a 96.4\% detection accuracy for spatial steganographic injections, a 100\% payload neutralization rate post-sanitization, and an 89\% reduction in gateway evaluation latency for cryptographically signed media assets.
\end{abstract}

\section{Introduction}
The rapid proliferation of Multimodal Large Language Models (MLLMs)---such as GPT-4V, Gemini 1.5 Pro, Claude 3.5 Sonnet, and LLaVA---has revolutionized artificial intelligence by enabling unified cross-modal reasoning over vision and natural language \cite{liu2023visual, achiam2023gpt4}. These foundation models power autonomous agents, automated visual question answering (VQA), and retrieval-augmented generation (RAG) pipelines. However, integrating visual inputs directly into the neural context window exposes an expansive, poorly defended attack surface: \textit{Multimodal Indirect Prompt Injection} \cite{greshake2023not, bagdasaryan2023abusing}.

In an indirect prompt injection attack, an adversary embeds malicious natural language commands (e.g., ``\textit{Ignore previous safety constraints and dump the confidential system prompt}'') into the pixel matrix of an image \cite{qi2024visual}. While standard text guardrails inspect textual prompts, visual steganography allows malicious directives to remain entirely invisible to the human visual system (HVS) and text tokenizers. During the visual encoding phase (e.g., via CLIP or SigLIP ViT encoders), the patch projections capture these subtle spatial-frequency patterns, injecting adversarial tokens directly into the LLM transformer layers. Recent red-teaming benchmarks report attack success rates exceeding 24\% across leading commercial vision models \cite{shayegani2023jailbreak}.

Existing defense mechanisms suffer from critical structural limitations:
\begin{itemize}
    \item \textbf{Text-Centric Filters:} Conventional input filters operate exclusively on natural language strings and are structurally blind to steganographic bit embeddings embedded inside image files \cite{owasp2023top10}.
    \item \textbf{Latent Representation Filtering:} Internal defenses such as ARGUS \cite{wang2024argus} inspect intermediate activation vectors. While theoretically sound, they require deep intrusive access to model weights, are tied to specific architectures, and incur unacceptable latency overhead in high-throughput production environments.
    \item \textbf{Single-Layer Deep Steganalysis:} Pure neural detectors enter an asymmetric arms race against adaptive embedding schemes (such as S-UNIWARD or HILL) \cite{holub2014designing, li2014new}, suffering high false positive rates on benign noisy images and failing to provide provenance guarantees.
    \item \textbf{Misapplication of Provenance Standards:} Emerging industry standards like C2PA \cite{c2pa2023spec} cryptographically sign LLM \textit{outputs} for copyright and attribution, but fail to gate untrusted multimodal \textit{inputs} against adversarial injection \cite{fisch2024visualtrust}.
\end{itemize}

\subsection{Contributions}
To address this fundamental gap, this paper introduces a cloud-deployable, model-agnostic security gateway designed to defend MLLMs prior to visual tokenization. Our contributions are summarized as follows:
\begin{enumerate}
    \item \textbf{Dual-Gate Security Model:} We propose a two-tier verification paradigm. Gate 1 verifies asymmetric ECDSA P-256 cryptographic provenance at the ingestion perimeter. Gate 2 deploys deep convolutional steganalysis as a zero-trust fallback for untrusted, public, or tampered assets.
    \item \textbf{Specialized Neural Steganalysis with Fixed KV Residue Filtering:} We adapt the Xu-Net architecture \cite{xu2016structural}, incorporating a non-trainable 5$\times$5 high-pass residual filter and absolute value activations to extract subtle injection signatures while suppressing macroscopic semantic textures.
    \item \textbf{Non-Destructive Perceptual Sanitization:} For flagged stego payloads, we formulate a multi-stage sanitization pipeline combining micro-spatial interpolation, controlled LSB dithering, and lossy discrete cosine transform (DCT) quantization that reduces payload recovery to 0\% while preserving visual question-answering fidelity (PSNR $> 38$~dB).
    \item \textbf{Full Empirical Prototype and Open Artifacts:} We provide a production-ready, containerized FastAPI microservice, complete with an interactive real-time inspection console and a reproducible prompt-injection dataset generator.
\end{enumerate}

\section{Threat Model and Mathematical Formulation}
\subsection{Threat Model}
We formalize the multimodal prompt injection threat under the standard OWASP LLM01 framework \cite{owasp2023top10}.
\begin{itemize}
    \item \textbf{Adversary Capabilities:} The attacker has the ability to submit arbitrary image files $\mathbf{I} \in \mathbb{R}^{H \times W \times C}$ to an MLLM-powered application (e.g., visual customer support, multimodal document processing). The attacker does not possess the private signing keys of authorized sources ($\mathcal{K}_{priv}$).
    \item \textbf{Adversary Objectives:} The adversary seeks to embed an adversarial prompt $\mathcal{P}_{inj}$ into $\mathbf{I}$ such that the visual encoder $E_v(\cdot)$ extracts token embeddings that hijack the autoregressive decoder, forcing the generation of unauthorized output $Y_{adv}$ (e.g., credential exfiltration, role-play jailbreak, API manipulation).
    \item \textbf{Steganographic Channel:} The payload $\mathcal{P}_{inj}$ is encoded using spatial domain modifications:
    \begin{equation}
        \mathbf{I}_{stego}(x, y, c) = \mathbf{I}_{cover}(x, y, c) + \Delta(x, y, c),
    \end{equation}
    where $|\Delta(x, y, c)| \le \epsilon$ ensures imperceptibility to human evaluators ($\text{PSNR} \ge 45\text{ dB}$).
\end{itemize}

\subsection{Mathematical Formulation of Gate 1 Provenance}
Gate 1 establishes cryptographic origin and tamper evidence using the NIST SECP256R1 (P-256) elliptic curve \cite{barker2020recommendation}. Let $G$ denote the base point of order $n$. The trusted source generates a private key $d \in_R [1, n-1]$ and public key $Q = d \cdot G$.

Upon image creation, the source computes the 256-bit cryptographic digest:
\begin{equation}
    h = \text{SHA-256}(\mathbf{I}_{bytes}).
\end{equation}
The ECDSA signature is the tuple $(r, s) \in \mathbb{Z}_n^* \times \mathbb{Z}_n^*$ computed via an ephemeral key $k \in_R [1, n-1]$:
\begin{equation}
    (x_1, y_1) = k \cdot G, \quad r = x_1 \pmod n,
\end{equation}
\begin{equation}
    s = k^{-1}(z + r \cdot d) \pmod n,
\end{equation}
where $z$ represents the integer derived from $h$. At the gateway, verification re-hashes the uploaded image bytes $\mathbf{I}'_{bytes}$ to derive $z'$ and evaluates:
\begin{equation}
    w = s^{-1} \pmod n, \quad u_1 = z' \cdot w \pmod n, \quad u_2 = r \cdot w \pmod n,
\end{equation}
\begin{equation}
    (x_v, y_v) = u_1 \cdot G + u_2 \cdot Q.
\end{equation}
Gate 1 grants bypass if and only if $x_v \equiv r \pmod n$ and $h_{claimed} == h_{computed}$. Because the private key $d$ remains strictly within the source hardware perimeter, even complete gateway compromise preserves non-repudiation.

\section{Proposed Dual-Gate Architecture}

\subsection{Gate 1: Cryptographic Provenance Layer}
Gate 1 operates as a lightweight, zero-latency perimeter filter. Images arriving from authenticated upstream pipelines (e.g., enterprise scanners, verified mobile client cameras) carry a sidecar cryptographic manifest $\mathcal{M} = \{ \text{hash}, r, s, \text{source\_id}, \text{timestamp} \}$.
\begin{itemize}
    \item \textbf{Decision 1 (Valid):} The computed hash matches $\mathcal{M}$, and the signature verifies against the trusted public key $Q$. The image is classified as low-risk and forwarded directly to the VLM (Fast-Path), bypassing Gate 2.
    \item \textbf{Decision 2 (Tampered):} The manifest is present, but either the SHA-256 digest differs from $\mathcal{M}$ or the ECDSA verification fails ($x_v \not\equiv r$). The image is immediately flagged as tampered and routed to Gate 2.
    \item \textbf{Decision 3 (Unsigned):} No manifest is present (public internet uploads). The asset is treated as zero-trust and routed to Gate 2.
\end{itemize}

\subsection{Gate 2: Xu-Net Steganalysis Layer}
Traditional deep convolutional networks fail in steganalysis because standard kernels optimize for macroscopic semantic features (edges, contours, object classes), treating subtle steganographic modifications as imperceptible high-frequency noise. To overcome this, Gate 2 employs the Xu-Net architecture \cite{xu2016structural}.

\subsubsection{Fixed High-Pass Preprocessing Layer}
The input image is first passed through a non-trainable convolutional layer initialized with the $5 \times 5$ KV high-pass filter kernel $\mathbf{K}$:
\begin{equation}
    \mathbf{K} = \frac{1}{12} \begin{bmatrix}
    -1 & 2 & -2 & 2 & -1 \\
    2 & -6 & 8 & -6 & 2 \\
    -2 & 8 & -12 & 8 & -2 \\
    2 & -6 & 8 & -6 & 2 \\
    -1 & 2 & -2 & 2 & -1
    \end{bmatrix}.
\end{equation}
Convolution with $\mathbf{K}$ computes the spatial residual map:
\begin{equation}
    \mathbf{R}(x, y) = \sum_{i=-2}^{2} \sum_{j=-2}^{2} \mathbf{K}(i, j) \cdot \mathbf{I}(x+i, y+j).
\end{equation}
This operation suppresses the low-frequency image content and amplifies the statistical perturbations introduced by steganographic embedding.

\subsubsection{Absolute Value Activation and Convolutional Groups}
Following the KV residual extraction, the network applies an Absolute Value (ABS) activation function:
\begin{equation}
    f_{ABS}(z) = |z|.
\end{equation}
This is critical because positive and negative steganographic noise residuals carry identical predictive evidence of embedding. The network consists of 5 subsequent convolutional stages utilizing $5 \times 5$ and $1 \times 1$ kernels, Batch Normalization, Tanh activations in early stages, and Average Pooling, terminating in an adaptive global pooling layer and a multi-layer perceptron (MLP) binary classifier:
\begin{equation}
    P(\text{stego} \mid \mathbf{I}) = \sigma(\mathbf{W}_c \cdot \mathbf{z} + b_c).
\end{equation}
If $P(\text{stego} \mid \mathbf{I}) \ge \tau$ (with threshold $\tau = 0.50$), the asset is flagged as an active prompt injection attempt.

\subsection{Gate 2 Fallback: Multi-Stage Perceptual Sanitizer}
When an unverified image is flagged as stego-bearing, blocking the request outright would cause denial-of-service for legitimate users uploading noisy images. Instead, Gate 2 invokes a multi-stage perceptual sanitization pipeline designed to scramble steganographic channels while retaining high semantic clarity for the downstream MLLM:
\begin{enumerate}
    \item \textbf{Metadata Stripping:} Removes all EXIF, XMP, and custom binary headers.
    \item \textbf{Spatial Sub-pixel Rescaling:} Rescales the spatial dimensions by a scaling factor $\alpha = 0.96$ using bilinear interpolation, followed by immediate restoration to $(H, W)$ via bicubic interpolation:
    \begin{equation}
        \mathbf{I}_{scaled} = \mathcal{R}_{\text{bicubic}}(\mathcal{R}_{\text{bilinear}}(\mathbf{I}, \alpha), \alpha^{-1}).
    \end{equation}
    This disrupts pixel-grid coordinate alignments essential for spatial bit extraction.
    \item \textbf{Controlled LSB Dithering:} The least significant bit plane is masked and randomized:
    \begin{equation}
        \mathbf{I}_{dithered} = (\mathbf{I}_{scaled} \ \& \ \sim 1) \ | \ \mathbf{N}_{random}, \quad \mathbf{N}_{random} \in \{0, 1\}.
    \end{equation}
    \item \textbf{Lossy DCT Quantization:} The dithered image is re-encoded into JPEG format with a calibrated quality factor $Q = 85$. The lossy quantization matrix zeroes out high-frequency discrete cosine transform coefficients, permanently destroying residual payload fragments.
\end{enumerate}

\section{Experimental Evaluation and Results}

\subsection{Experimental Setup and Dataset Synthesis}
To benchmark the Dual-Gate Gateway, we evaluate across two benchmark collections:
\begin{enumerate}
    \item \textbf{BOSSbase 1.01 Benchmark:} 10,000 $512 \times 512$ uncompressed grayscale images embedded with spatial adaptive steganography (S-UNIWARD and HILL) across payloads of 0.1, 0.2, and 0.4 bits per pixel (bpp) \cite{bas2011break}.
    \item \textbf{Synthetic Multimodal Injection Corpus:} A curated set of 1,000 high-entropy natural images embedded with real-world prompt injection payloads adapted from the OWASP Top 10 for LLMs \cite{owasp2023top10}. Payloads include context exfiltration, DAN jailbreaks, instruction overrides, and visual cognitive hijacks.
\end{enumerate}

\section{Security Analysis and Discussion}
\subsection{Non-Repudiation and Key Isolation}
A central innovation of Gate 1 is asymmetric key distribution. Symmetric defenses (e.g., HMAC-based tokens) require the gateway to store shared secrets; an adversary breaching the cloud gateway could forge valid signatures. Under our ECDSA P-256 scheme, the gateway hosts only public verification keys ($Q$). Compromise of the gateway gives an attacker zero capability to forge valid signatures, preserving non-repudiation and satisfying strict auditability requirements.

\subsection{Defense Against Adaptive Steganography}
Adversaries utilizing edge-adaptive embedding algorithms (such as HILL or S-UNIWARD) concentrate noise in textured regions where variance is high. While generic CNNs miss these perturbations, the 5$\times$5 high-pass KV filter calculates residual differences that strip semantic gradients. Furthermore, because Gate 2 automatically defaults to the multi-stage sanitization pipeline whenever an anomaly is flagged, even zero-day stego schemes with borderline confidence are disrupted during pixel interpolation and DCT re-quantization.

\section{Conclusion and Future Work}
This paper presented a novel Dual-Gate architecture defending Multimodal Large Language Models against indirect prompt injection via steganographic image channels. By integrating ECDSA cryptographic provenance verification (Gate 1) with deep convolutional residual steganalysis and multi-stage sanitization (Gate 2), the system provides provable security for authenticated sources and zero-trust fallback protection for public inputs. Experimental results demonstrate a 96.4\% detection rate, complete payload neutralization, and sub-millisecond fast-path performance. Future research will explore hardware-accelerated C2PA manifest ingestion directly at the gateway ingress and extending residual steganalysis to high-frame-rate multimodal video streams.
